House Price Prediction Using Machine Learning

**Project Overview**

This project predicts house prices based on the house area, number of bedrooms, and number of bathrooms using Machine Learning.

**Objective**

The main objective is to build a model that estimates the price of a house using its features.

**Technologies Used**

- Python
- Pandas
- NumPy
- Scikit-learn
- Linear Regression
- VS Code

**Dataset Description**

The dataset contains 20 sample house records with the following columns:

- area_sqft: Area of the house in square feet
- bedrooms: Number of bedrooms
- bathrooms: Number of bathrooms
- price_lakhs: House price in lakhs

**Machine Learning Algorithm**

Linear Regression is used to learn the relationship between house features and house prices and predict a price for a new house.

**Sample Prediction**

- Area: 1500 square feet
- Bedrooms: 3
- Bathrooms: 2
- Predicted Price: 60.69 lakhs

**Model Evaluation**

- Mean Absolute Error (MAE): 0.55
- R² Score: 1.0

Note: These evaluation results are based on the current small sample dataset and should not be treated as proof of real-world accuracy.

**Project Files**

- "main.py" — Python code for the project
- "house_data.csv" — House dataset
- "dataset_output.png" — Screenshot of dataset output
- "prediction_output.png" — Screenshot of prediction output

**Conclusion**

This beginner-level project demonstrates how Python and Linear Regression can be used to predict house prices from house features.
